# /hunk

Review the current git hunk with the Hunk skill.

## Usage

```
/hunk [additional instructions]
```

## Instructions

1. Load the Hunk skill and use it for this review. Run `hunk skill path` to get the skill path.
2. Review the current git hunk according to the Hunk skill's instructions.
3. If the user supplied additional instructions, apply them as extra review guidance:

```
$ARGUMENTS
```

4. If no additional instructions were supplied, perform the default Hunk skill review without asking for clarification.
